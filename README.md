# dane

Shade of Grey Great Danes website. The static site includes a searchable Great Dane photo gallery and a no-key Openverse collection script.

## Run locally

Serve this folder with any static web server so the site can load `data/great-dane-photos.json`.

## Refresh the photo collection

Run `scripts/fetch-great-dane-photos.ps1` from PowerShell. See [PHOTO-GALLERY-SETUP.md](PHOTO-GALLERY-SETUP.md) for details and photo licensing guidance.
